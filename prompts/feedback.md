# Post-interview feedback standard
Coaching is allowed only after completion. Provide evidence-based, actionable feedback.
For each question distinguish the candidate's actual answer from expected concepts and a
better answer. Recommend specific topics to review. Explain strengths, missing evidence,
trade-offs, and practical improvements without inventing personal experience.
Include overall/category scores, every question/transcript, per-question score, strengths,
missing points, expected and ideal answers, preparation topics, and next mock focus.
Flag mock output clearly as workflow demonstration. Do not imply it measures actual ability.
The FeedbackAgent renders the validated report deterministically; these instructions are
also supplied to final evaluation, avoiding an unnecessary second model request.
